# 📦 AetherTrack - Intelligent Warehouse Monitoring System

**AetherTrack** adalah konsep Tech-Startup yang menyediakan solusi pemantauan gudang pintar berbasis Internet of Things (IoT). Sistem ini dirancang khusus untuk membantu perusahaan logistik dan manufaktur (khususnya di kawasan industri Batam) dalam mencegah kerusakan aset sensitif akibat fluktuasi suhu dan kelembapan.

## 🚀 Latar Belakang Masalah
Banyak gudang elektronik dan farmasi di Batam masih mengandalkan pencatatan suhu manual. Hal ini rentan terhadap *human error* dan keterlambatan respons jika terjadi kegagalan sistem pendingin, yang berujung pada kerugian finansial yang masif.

## 💡 Solusi (Value Proposition)
AetherTrack mengintegrasikan sensor cerdas (IoT) dengan *dashboard* analitik berbasis *cloud*. Fitur utamanya meliputi:
* **Pemantauan 24/7:** Visibilitas *real-time* untuk suhu dan kelembapan.
* **Automated Alerts:** Notifikasi instan via email/dashboard jika parameter melewati batas aman.
* **Cloud Sync:** Manajemen data secara terpusat untuk kemudahan audit.

## 🛠 Spesifikasi Teknologi
* **Hardware:** Modul Sensor Industrial (Suhu & Kelembapan) dengan konektivitas nirkabel LoRaWAN/WiFi.
* **Software Front-End:** UI/UX Dashboard dirancang dengan Figma, Landing Page dibangun menggunakan HTML5 dan Bootstrap 5.
* **Software Back-End (Rencana Pengembangan):** Framework Laravel, PHP, dan MySQL untuk manajemen database.

## 💻 Cara Menjalankan Proyek (Landing Page)
Proyek ini memuat MVP (Minimum Viable Product) berupa *Landing Page* statis. Untuk melihat hasilnya di komputermu, ikuti langkah berikut:

**Cara 1: Buka Langsung di Browser**
1. Unduh (*Download ZIP*) atau *clone repository* ini ke laptopmu.
2. Ekstrak folder jika mengunduh dalam format ZIP.
3. Klik dua kali pada file `index.html`.
4. Halaman akan otomatis terbuka di *browser* default kamu (Chrome, Edge, atau Firefox).

**Cara 2: Menggunakan Local Server (Visual Studio Code)**
1. Buka folder proyek ini menggunakan Visual Studio Code.
2. Pastikan kamu sudah menginstal ekstensi **Live Server**.
3. Klik kanan pada file `index.html` lalu pilih **"Open with Live Server"**.
4. Halaman akan terbuka di *browser* dan akan otomatis me-refresh jika ada perubahan kode.
